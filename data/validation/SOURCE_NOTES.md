# Administrative comparison data

`dos_visa_consumption_reconciled.csv` supplies FY2009–FY2024 category–nationality issuance targets. The FY2024 EB-1 ROW subtotal is reduced by 268 to reconcile to the published category total; the manuscript describes this adjustment.

`submitted_sensitivity_ageout_summary.csv` is a historical archive of the original sensitivity results. It is not evidence for the current model. The manuscript now uses the corrected-input parameter sweep in `data/runs/parameters-inflation-corrected-20260923/`. The original CSV is retained only for provenance.

The table bytes were preserved from the prior analysis; restructuring did not reestimate their values.
